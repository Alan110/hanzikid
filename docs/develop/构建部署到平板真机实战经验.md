## 二、一次性配置

### 1. USB 驱动：HDC Interface 驱动缺失（错误码 28）

**现象**：平板 USB 连电脑，设备管理器「其他设备」出现 `HDC Interface`（USB\VID_12D1&PID_1101&MI_00，类 FF/50/01）带黄色感叹号，`hdc list targets` 看不到设备。

**走过的弯路**：
- Windows Update 搜不到华为驱动
- HiSuite 16 装了没用：其 driverinfo.xml 的 PID 列表**不含 1101**（NEXT 架构设备的 HDC 接口）；HiSuite 14 只适用 HarmonyOS 4
- 注册表 UpperFilters 检查正常，无需清理

**正确解法（华为官方 FAQ 推荐）**：用 [Zadig](https://github.com/pbatard/libwdi/releases)（v2.9）给 `HDC Interface (Interface 0)` 安装 **WinUSB** 驱动：
1. 平板开启「开发者选项 → USB 调试」，USB 连电脑
2. Zadig → Options → List All Devices → 下拉选 `HDC Interface (Interface 0)`
3. 目标驱动选 WinUSB → Replace Driver
4. 完成后设备管理器恢复正常，`hdc list targets` 显示序列号

### 2. 签名：devecocli 一键生成

```
devecocli signature generate --product default
```
- **必须在 `harmony-app/` 工程根目录下执行**（读 build-profile.json5 的 product）
- 引导登录华为账号后，自动生成 p12/cer/p7b 到 `C:\Users\<user>\.ohos\config\`，并写入 `build-profile.json5` 的 signingConfigs
- 之后 hvigor 构建自动签名（SignHap 任务）

## 三、日常构建部署流程（速查）

改完根目录 `index.html` 后的标准流程：

```
# 1. 同步 H5 到鸿蒙工程 rawfile（根目录执行）
./sync-game.sh

# 2. 构建（harmony-app/ 下）
build_project                        # 或 hvigor assembleHap

# 3. 部署启动（一步到位：装最新 HAP + 拉起）
start_app --device 3GLUN24613G05978

# 或手动：
hdc app install -r entry-default-signed.hap
hdc shell "aa start -a EntryAbility -b com.alan.hanzikid"

# 重启应用（不重装）
hdc shell "aa force-stop com.alan.hanzikid"
hdc shell "aa start -a EntryAbility -b com.alan.hanzikid"
```

产物位置：`harmony-app/entry/build/default/outputs/default/entry-default-signed.hap`

## 四、常见坑

| 现象 | 处理 |
| --- | --- |
| 启动报 `10106102`（屏幕锁定） | 开发者模式下系统不会自动解锁屏幕。先点亮解锁平板；调试期间把 设置→显示→休眠 调到 10 分钟以上 |
| 设备变 Offline | 重新插拔 USB 或重开 USB 调试，必要时 `hdc kill` / `hdc start` |
| `devecocli run` 偶发 E000004 通道错误 | 应用已装上时直接用 `hdc shell "aa start ..."` 启动，效果一样 |
| 设备列表混入 COM 口 UART 条目 | hdc 噪音，忽略；`start_app` 显式指定设备序列号 |

## 五、白屏排查实录（重要）

### 症状
应用装上、能启动、进程活着，但整个窗口纯白。无闪退、无 jscrash。

### 排查方法论（由轻到重，先取证再读码）

1. **查崩溃日志**：`/data/log/faultlog/faultlogger/` 下无 jscrash → 排除 JS Crash
2. **导出 UI 节点树**（文本可分析，白屏问题的黄金证据）：
   ```
   devecocli ui layout --device <sn> --mode simplified --depth 6
   ```
   当时结果只有窗口容器 `Stack#ContainerModalStack`，无任何内容节点 → 页面根本没渲染
3. **清日志 → 复现 → 抓启动期 hilog**：
   ```
   hdc shell "hilog -r"                       # 清缓冲
   hdc shell "aa start -a ... -b ..."         # 复现
   hdc shell "hilog -z 4000" > launch.log     # 抓快照
   ```
4. **顺日志链定位**，关键三行：
   ```
   Base:   GetEntry from resources/base/profile/.json err        ← 空文件名！
   WindowSessionImpl: SetUIContentInner: failed to init or restore
          uicontent with file pages/Index. errorCode: 13
   EntryAbility: Failed to load content. Cause: {"code":401}
   ```
5. **解剖 HAP 包对比官方模板**（HAP 就是 zip，PowerShell 直接开）：包内编译产物 `module.json` 的 module 节点缺 `pages` 字段，而 DevEco 自带官方模板（`DevEco Studio\plugins\codegenie-plugin\previewProjectTemplate\...\module.json5`）里有 `"pages": "$profile:main_pages"`
6. **根因**：`module.json5` 缺 `"pages": "$profile:main_pages"` → 运行时拿空字符串去读 `resources/base/profile/.json` → 页面配置加载失败 → `loadContent` 401 → 白屏

### 修复（已合入工程）
1. `harmony-app/entry/src/main/module.json5` module 节点补 `"pages": "$profile:main_pages"`
2. 连锁反应：补上后编译器真正开始编译页面，暴露 `javaScriptProxy` 写在 `Web({})` 构造参数里的错误——它实际是**链式属性**：
   ```ts
   // 错：Web({ src, controller, javaScriptProxy: {...} })
   // 对：
   Web({ src: $rawfile('index.html'), controller: this.controller })
     .javaScriptProxy({ object: ..., name: 'HanziNative', methodList: [...], controller: this.controller })
     .domStorageAccess(true) ...
   ```
3. TTS `speak()` 加 try-catch 消除告警

### 验证（证据闭环）
- 重构建后解包确认 HAP 内 `module.pages = $profile:main_pages`
- 启动后再导 UI 树：`Web "resource:/RAWFILE/index.html"` 节点出现，游戏主界面（标题/玩法/词库分类）全部可见 → 修复确认

## 六、沉淀的通用经验

1. **「能装、能启动、纯白屏、无崩溃」** → 大概率是 `loadContent` 失败（页面路由/配置问题），直接搜 hilog：`Failed to load content`、`SetUIContentInner`、`errorCode`
2. **UI 树 dump（`devecocli ui layout`）是白屏类问题的黄金证据**：纯文本、可精确判断「渲染了什么/没渲染什么」，比截图客观
3. **HAP 就是 zip**：PowerShell 用 `System.IO.Compression.FileSystem` 直接开包看 `module.json`、`.pages.info`、`resources/`，和官方模板 diff 是定位打包配置问题的捷径
4. **官方模板就在本机**：`DevEco Studio\plugins\codegenie-plugin\previewProjectTemplate\`，不用上网查「标准配置长什么样」
5. **修一个配置可能连环暴露编译错误**（pages 注册后页面才真正参与编译）——属正常现象，逐个修即可
6. 本工程结构：`Index.ets` 里 `Web({ src: $rawfile('index.html') })` 加载 `entry/src/main/resources/rawfile/index.html`；改根目录 H5 后必须先跑 `sync-game.sh` 再打包
7. hilog 缓冲区滚动快，抓启动问题务必**先清缓冲再复现**，别事后翻全量日志
